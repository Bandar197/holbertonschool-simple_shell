# Simple Shell

# Description

This project is simple UNIX command interpreter written in C 
The shell reads commands from the user and executes them.

# Compilation

Compile the program with:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o hsh

# Usage:

Run the shell with:
./hsh

Example:

($) /bin/ls
